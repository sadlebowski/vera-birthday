# Папка для музыки (Audio)

Сюда ты можешь закинуть любимые музыкальные треки Веры (например, ваши романтические песни, lo-fi, или саундтрек из Alice: Madness Returns).

### Как добавить музыку:
1. Положи файлы в формате `.mp3` прямо в эту папку `public/assets/audio/` (например, `music_box.mp3`, `lofi_theme.mp3`).
2. В файле `src/config/memories.js` в секции `playlist` укажи название трека, исполнителя и путь:
```javascript
playlist: [
  {
    title: "Название песни",
    artist: "Исполнитель",
    src: "./assets/audio/твоя_песня.mp3"
  }
]
```

*Примечание:* Если mp3 файлов пока нет, игра автоматически запустит встроенный ностальгический синтезатор музыкальной шкатулки через Web Audio API, поэтому звук будет работать сразу без ошибок!
