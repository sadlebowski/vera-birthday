# Папка для фотографий (Photos)

Сюда нужно положить ваши совместные фотографии и памятные снимки Веры.

### Рекомендуемые имена файлов:
- `photo1.jpg` — Первая глава (первые моменты / начало)
- `photo2.jpg` — Первая глава
- `photo3.jpg` — Вторая глава (прогулки / приключения)
- `photo4.jpg` — Вторая глава
- `photo5.jpg` — Третья глава (красивые портреты / вдохновение)
- `photo6.jpg` — Третья глава
- `photo7.jpg` — Финал (праздничное фото рядом с тортом)

*Форматы:* `.jpg`, `.jpeg`, `.png`, `.webp`.

Если названия или количество фото отличаются, ты можешь в любой момент отредактировать пути в файле `src/config/memories.js`!
Если фото еще не добавлены, игра автоматически нарисует эстетичные винтажные постеры с блестками и наклейками.
