# Папка для 3D моделей (Models)

В игре уже встроена процедурная low-poly модель Алисы в каноничном викторианском синем платье, с фартуком, полосатыми чулками и анимациями.

Если ты захочешь использовать оригинальную модель из *Alice: Madness Returns*:
1. Экспортируй или скачай модель Алисы в формате `.glb` или `.gltf`.
2. Положи её в эту папку с именем `alice.glb`.
3. Код в `src/entities/Alice.js` легко расширяется на использование GLTFLoader.
