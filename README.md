# 🎀 "Alice in the Scrapbook of Memories" — Подарочная 3D игра-открытка ко Дню Рождения Веры 🎂✨

Интерактивная игра-открытка на **Three.js + Vite** в эстетике старого Tumblr, MySpace и Pinterest (Y2K / 2000s web, полароиды, бантики, кружева, мягкий PS1-дизеринг).

---

## 🌟 Как устроена игра:
1. **Интро-сцена**: На винтажном столе в окружении кассеты, чайной чашки и старинного ключа лежит запечатанная открытка.
2. **Открытие открытки**: При клике на сургучную печать открытка распахивается с 3D анимацией, вырастают поп-ап декорации и включается музыка в стиле MySpace.
3. **2.5D Платформер с Алисой**: Камера подлетает, появляется пиксельная Алиса в синем викторианском платье и полосатых чулках (*Alice: Madness Returns*). Игрок бежит сквозь развороты фотоальбома её жизни.
4. **Перелистывание страниц**: Достигнув правого края страницы, разворот с шелестом физически переворачивается в 3D на следующую главу воспоминаний.
5. **Кульминация на финальной странице**: Алиса подбегает к праздничному торту с зажженными свечами. Нажав ПРОБЕЛ или кликнув, свечи задуваются, взлетает праздничный фейерверк из конфетти и бабочек, и открывается трогательное письмо-поздравление!
6. **Винтажный MySpace/Winamp аудиоплеер**: Крутящаяся кассета, бегущая строка, список треков и возможность закинуть любые любимые песни.

## 🚀 Быстрый запуск для разработки

1. Открой терминал в этой папке:
   ```bash
   cd "D:\VIBE_CODING\project\Game for girlfriend"
   ```
2. Установи зависимости:
   ```bash
   npm install
   ```
3. Запусти сервер разработки:
   ```bash
   npm run dev
   ```
4. В браузере автоматически откроется ссылка: `http://localhost:3000`.

## 📸 Как наполнить открытку своими фото и текстами (Zero-Code):

### 1. Фотографии
Положи фото в папку `public/assets/photos/`:
- `photo1.jpg`, `photo2.jpg` — 1-я глава
- `photo3.jpg`, `photo4.jpg` — 2-я глава
- `photo5.jpg`, `photo6.jpg` — 3-я глава
- `photo7.jpg` — финальное фото около торта

### 2. Тексты, даты и поздравление
Открой файл `src/config/memories.js` и настрой:
- `recipientName`: Имя именинницы;
- `chapters`: Заголовки глав, даты и текст всплывающих записок воспоминаний;
- `finaleLetter`: Главный текст твоего признания и поздравления (поддерживает переносы строк и эмодзи);
- `playlist`: Названия твоих песен и исполнителей.

### 3. Музыка
Закинь `.mp3` файлы в папку `public/assets/audio/` и укажи их в `src/config/memories.js`.
*(Если файлов пока нет, игра сама сыграет милую шкатулку через встроенный синтезатор!)*

## 🌐 Как бесплатно опубликовать в интернет (для отправки ссылки девушке)

### Вариант 1: Vercel (Самый быстрый, 1 минута)
1. Собери проект в статику:
   ```bash
   npm run build
   ```
2. Зайди на [vercel.com](https://vercel.com).
3. Перетащи мышкой папку `dist` прямо в окно браузера на страницу проектов Vercel.
4. Получи красивую секретную ссылку вида `https://happy-birthday-vera.vercel.app` и отправь её ей!

### Вариант 2: Netlify Drop
1. Зайди на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащи собранную папку `dist`.
3. Ссылка готова мгновенно!
